### Claim (narrow form)

For the 14 May 2024 CME, four Type II bursts are best located near the CME flanks at different coronal heights where PFSS open field intersects low-Alfvén regions — consistent with super-Alfvénic (M_A≈3.2–3.6) shock formation at the shoulders.

### Method assumptions

- Density model + I-LOFAR drift rate → shock height.
- PFSS + MHD give complementary ambient conditions.
- CME tracking via WL + EUV is accurate to the necessary tolerance.

### Data assumptions

- I-LOFAR 10–240 MHz spectra.
- SOHO/LASCO + GOES-SUVI imagery.
- Synoptic Br for PFSS; MHD ambient for the event.

### Failure modes (skill memory)

- Density-model choice changes derived heights materially.
- PFSS doesn't capture pre-CME current-sheet structure.
- Burst association (which feature → which Type II) is non-trivial.

### Figure / numerical targets

- Combined dynamic spectrum with the four Type II bursts.
- CME front + flank position overlaid on PFSS open field.
- Shock-speed and M_A timeline.

### Claim boundary

**In scope.** 14 May 2024 CME with paper's PFSS+MHD ambient.

**Out of scope — do NOT generalize:**

- Do NOT cite shock heights without naming the density model.
- Do NOT use the M_A≈3 range as a generic value for all multi-shock CMEs.

## Layer 2 — Executable protocol (capability-typed)

### Required capabilities (abstract)

| Capability | Purpose | Notes |
|---|---|---|
| `radio.dynamic_spectrum()` | Type II identification | LOFAR |
| `density.coronal_model()` | ne profile | Newkirk/Saito/2x |
| `imagery.fetch_lasco()` | WL coronagraph | C2/C3 |
| `imagery.fetch_suvi()` | EUV imagery | GOES-SUVI |
| `pfss.solve()` | open-field ambient |  |
| `mhd.ambient()` | MHD ambient | external |

### Procedure

1. Identify Type II bursts; extract drift rates.
2. Convert drift rates to shock heights via density models.
3. Track CME via WL+EUV.
4. Solve PFSS for the CR; obtain ambient MHD if available.
5. Localise bursts to CME flanks vs front; compute M_A.

### Validation target

Match the four-burst sequence and M_A≈3.2–3.6 ordering.
