## How to run the audit

```bash
# Default human-readable summary + top-30 ranking
python3 scripts/audit_internalization_readiness.py

# Wider ranking, write to a file
python3 scripts/audit_internalization_readiness.py --top 100 \
    --output reports/internalization_readiness_long.txt

# Machine-readable JSON (suitable for downstream tooling)
python3 scripts/audit_internalization_readiness.py --json | jq '.summary'

# CI gate — only fail if active entries drop below the floor
python3 scripts/audit_internalization_readiness.py --strict-active \
    --min-active-score 55
```

Tests pinning the audit's stable invariants live in
`tests/test_internalization_readiness.py`. They cover both a synthetic
2-entry fixture corpus and the live 501-entry corpus.
